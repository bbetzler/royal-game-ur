# Project Royal Game of Ur

This repository is to implement a version of the board game The Royal Game of Ur.

## Royal Game of Ur

This board game is a historic and archeologic board game. See the following references:

https://en.wikipedia.org/wiki/Royal_Game_of_Ur
https://www.britishmuseum.org/collection/object/W_1928-1009-378
https://royalur.net/
https://www.tradgames.org.uk/games/Royal-Game-Ur.htm

## Target devices and deployement

Primary target devices are mobile devices, phones and tablets with Android. The primary display form factor is for mobile phones.

Secondary targets are iOS mobile devices as well as browsers, desktops, Windows, Linux.

## Technology stack

PWA with Vue/React as UI framework. Simple hosting for download on GitHub pages.
